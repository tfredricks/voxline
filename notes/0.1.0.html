First beta build of voxline. - Hold-to-dictate hotkey with on-device Whisper transcription - Optional LLM cleanup pass with custom vocabulary - Settings UI with hotkey, model, and API key configuration - Automatic update checks via Sparkle (this version and onward) Known limitations: - Apple Silicon only (no Intel build) - macOS 14.0+ - Early beta — please report issues at https://github.com/tfredricks/voxline/issues
