# Feature Roadmap

1. [x] **Works anywhere you type** — Dictate into any active text field: browser, email, docs, chat apps, notes, terminals, IDEs, and desktop apps.
2. [x] **Fast push-to-talk capture** — Hold a hotkey, speak, release, and the text appears quickly with minimal friction.
3. [x] **High-quality speech-to-text transcription** — Accurately converts spoken words into text with strong handling of accents, casual speech, pauses, and background noise.
4. [x] **AI cleanup of natural speech** — Removes filler words, false starts, repeated phrases, awkward pauses, and rambling phrasing.
5. [x] **Automatic punctuation and capitalization** — Adds periods, commas, question marks, paragraph breaks, and capitalization without requiring spoken punctuation commands.
6. [x] **Natural speech to polished writing** — Converts conversational dictation into clear written language instead of dumping a raw transcript.
7. [ ] **Command-based editing and rewriting** — Supports voice commands such as "make that shorter," "turn that into bullets," "rewrite that more professionally," "make it friendlier," "summarize this," or "rewrite in a casual tone."
8. [ ] **Custom vocabulary** — Lets users add names, company terms, acronyms, technical terms, product names, and personal shorthand so transcription gets them right.
9. [ ] **Custom snippets and reusable phrases** — Triggers saved blocks of text by voice, such as email signatures, common replies, boilerplate paragraphs, or canned status updates, with optional personal and shared libraries.
10. [ ] **Personal writing style adaptation** — Learns user preferences over time, such as sentence length, tone, sign-offs, formatting habits, and common phrases.
11. [x] **Context-aware formatting** — Adjusts output based on where the user is typing: email reply, Slack message, document, code comment, task note, or search box, using cues from the active app, nearby text, and selection.
12. [ ] **Low-friction correction flow** — Makes it easy to fix mistakes by voice, quick keyboard shortcut, inline rewrite, or selecting recent dictated text.
13. [ ] **Voice notes to structured output** — Turns rough spoken thoughts into notes, emails, memos, task lists, summaries, or outlines.
14. [ ] **App-specific integrations** — Adds enhanced support for common apps like Gmail, Outlook, Slack, Teams, Notion, Google Docs, Word, VS Code, Cursor, and ChatGPT.
15. [ ] **Developer and coding workflows** — Recognizes variable names, function names, and technical terms across languages like JavaScript, TypeScript, Python, Swift, Rust, and Go; works smoothly in IDEs, terminals, and coding agents, with chunking for long prompts.
16. [ ] **Multilingual dictation and translation** — Dictates in multiple languages with automatic detection and optional translation to English for cross-language writing.
17. [ ] **Audio file and meeting transcription** — Transcribes imported audio or video files, meeting recordings, and call captures, with optional speaker labels, summaries, and action items.
18. [ ] **Privacy controls** — Gives users clear control over audio retention, transcript history, logging, model providers, no-data-retention options, and what gets sent to APIs.
19. [x] **Dictation history** — Keeps the last 10 cleaned dictations in a menu-bar submenu; click a row to copy it to the clipboard.
20. [ ] **Prompt/template presets** — Lets users save reusable output formats like "client email," "meeting note," "GitHub issue," "daily journal," or "technical explanation."
21. [x] **Configurable hotkeys and behavior** — Custom push-to-talk shortcut, microphone selection, and LLM cleanup provider/model selection.
22. [x] **Visible status and feedback** — Shows when the app is listening, processing, inserting text, or waiting for correction.
23. [ ] **Cross-device availability and sync** — Extends dictation beyond macOS to Windows and iOS, and syncs custom vocabulary, snippets, style preferences, and settings across devices while keeping transcripts local.
24. [ ] **Local LLM for cleanup tasks** — Install, manage, and use a local LLM for privacy-first usage so transcription and cleanup happen entirely on the local machine.
